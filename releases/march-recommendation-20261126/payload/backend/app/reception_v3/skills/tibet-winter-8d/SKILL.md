# 2026-11-25 業務修正：拼團入藏日期（優先於一般提前住宿建議）
本公司西藏拼團的入藏函按團辦理，一個團一張。客人不能自行提前進西藏再等原團集合；林芝、拉薩都屬西藏。不得建議「提前一天到林芝住一晚」「把提前日期填進入藏函就好」或保證另訂酒店即可提前入藏。已經說錯時要明確更正前面的建議，不能沿用錯誤承諾。這是本公司團體接待規則，不擴寫成所有旅客的普遍法律結論。
2–3位按本團核准的入藏日期一起安排，不替客人改成4位。桃花團客人日期不合時，可以說「我們4位可以申請另開新團期，在該行程開放日期內安排；入藏函也要按新團一起辦理」，不把4人指定開拼團說成免費獨立包團，不保證申請必成或任何日期都能走。其他西藏線的四人方案依該線配置核對，阿里不套普通拼團優惠。
桃花2–3位要求提前入藏時，說明限制後要補充四位可申請另開新團期這個替代方案，不能只叫客人改日期。客人說「另開團期／新開一團」不等於「不拼其他人／包團」：沒有明確獨團意願，不得寫profile.group_type=private，也不得為了查非定班日而把get_departure_quote的group_type傳private。核對定班與申請新拼團是不同事項；工具沒有現成定班不妨礙提出四位申請方案，但不能說已確認可出發。只有客人明確要求不拼其他人時才用獨團條件與加價；這條優先於四人自選日期工具提示中的獨團示例。
已知2–3位說「4月1日到林芝」而查到最近定班4月2日，也屬本規則：列出可核對的定班後，必須補充不能4/1先入藏等4/2的原團，以及湊到4位可申請新團期；不必等客人再次追問入藏函才說。查四位新拼團日期時用group_type=shared查現有定班，不能用undecided繞進private_departure；可另行說明申請新拼團須由顧問確認，不寫成定班工具已核准。
提前到成都等西藏以外城市、在成都過夜交函，不等於提前入藏，可按已確認交通安排說明；獨立包團也必須先由顧問確認整團入藏日期和文件，不能讓客人先飛入藏再補辦。只問規則可以直接答；已買提前入藏機票或要求例外安排，說明不能直接沿用原團，交顧問核對，不能保證能用原函。

# 2026-11-25 首次詢價：先看用車與住宿，再報價

客人首次問團費且本線的車輛/住宿尚未實際發送成功時，本輪順序是：一句過渡「我先跟您介紹我們車子跟住宿的安排，這樣您會更清楚費用包含哪些服務～」→本線車輛的簡短說明及1張匹配照片→本線住宿的簡短說明及1張匹配照片→本輪有依據的報價/起價與必要日期條件。不要只發過渡就等客人同意；不要改成先報價後補照片；不要重播整套景點、自我介紹或索取聯絡方式作報價前提。
只使用當前線路、季節及團型適用的事實和available_materials內可用的asset_keys；不要拿其他線路的酒店、車型或已停用照片替代。文字精簡，不聲稱唯一、保證供氧、保證房間或不存在的升級。沒有匹配可用圖時用有依據的短文，不能為了等圖不報價。不要把機票價、小費、單房差等單項費用問題誤當首次團費詢價。

介紹進行中遇到首次團費詢價：action=reply、interrupt=true、start_introduction=false，用messages按上述次序一次輸出尚缺的車/住宿圖文和報價，停止舊的景點介紹草稿，不能queue到不確定的以後，也不能只報起價導致車和酒店永久漏掉。每個說明可用text+asset_keys，報價仍用現有核價工具給出的script_id/quote_options或有效starting_price_evidence，不能自行改算價格。僅說明車和酒店的消息is_trip_quote=false，真正報價才is_trip_quote=true，沿用報價實際發送後5分鐘邀請機制。
