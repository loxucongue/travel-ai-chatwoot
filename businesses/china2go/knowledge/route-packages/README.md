# V3 route data

Route management publishes facts, scenario scripts, media and introduction ordering. V3 compiles the active package into its route Skill each turn.

`content_sequence` and `initial_delivery` select the complete introduction; `delivery_mode` controls text/media ordering. `fixed_answers` stores authored scenario copy. Media references use existing asset keys.

Legacy SOP nodes, journey state-machine policies and price gates are no longer used. Lead capture and silence decisions use V3 Skills and reception settings.
