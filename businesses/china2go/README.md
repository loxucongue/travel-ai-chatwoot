# 原公司业务隔离包

来源：原项目提交 `90cbd6f`。此目录不在 Rujing2 部署白名单中。

- `knowledge/`：从 `data/knowledge/china2go/` 原样迁移的路线包、报价表、官网知识、图片和材料。
- `skills/`：原接待及线路 Skill，保留原文。
- `system-prompt.txt`：从原 V3 prompt 模块提取的完整业务提示词。
- `reception-defaults.json`：原默认接待配置。
- `profile.json`：原公司身份、产品分组、默认跟进文案及特有报价说明。

旧公司仍在 `main` 维护和部署。本目录为开发者追溯和回归使用，不是同步原生产数据库的备份。
包内的历史来源路径按原提交保留，涉及旧路径的维护脚本应在原分支执行。
客户会话、数据库、生产密钥及未提交的服务器上传文件均未迁入。
