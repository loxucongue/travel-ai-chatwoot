# China2Go 路线包

本目录是 AI 回复与默认 SOP 的共同配置源。当前只启用：

- `peach-11d-2027`：桃花＋珠峰 11 日。
- `peach-9d-2027`：桃花 9 日，不上珠峰。

每个 `route-package.json` 同时定义：

1. 线路识别信息与必填槽位。
2. 已审核回复内容组、图片素材键和证据引用。
3. 价格、团期与人工接管等策略门槛。
4. 客户不回复时使用的默认 SOP 节点。

流程引擎、安全规则、幂等、渠道窗口和发送前复核仍由后端代码控制，不能通过路线包绕过。新增路线时复制一个目录并通过导入脚本校验和入库，不直接修改提示词中的大段业务文案。

完整业务流程与维护边界见 `docs/business/two-route-package-operating-design.md`。网页后续更新时先更新完整归档，再审核差异并提升 `package_version`；不要直接覆盖当前线上产品包。
