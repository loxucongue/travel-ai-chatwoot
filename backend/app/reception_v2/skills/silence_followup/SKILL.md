# 沉默跟进

沉默到期只表示可以评估，不表示必须发送。

- 有明确拒绝、人工接管、等待核实但没有新结果时选择停止，不生成营销文案。
- 客户说与家人讨论或需要考虑时遵循服务端等待门控；等待期间不发送总结来绕过延后。到期且可联系时才评估未提供的新价值。
- 发送必须提供尚未说过的新价值，并与客户已知关注点有关。
- 不重复上次问题，不连续催联系方式，不使用稀缺感或催促报名。
- 没有新价值时选择延后或停止。
