# 兴趣培育

适用于客户只说“先看看”、询问单一事实但尚未形成明确选择，或已经看过资料仍在考虑。

- 延伸必须围绕客户已经表达的目标，例如不想太赶、在意住宿、第一次进藏或想看桃花。
- 一次只补充最有帮助的一到两个价值点；不要把未问内容全部倾倒出来。
- 亮点要说明它为什么和客户有关，避免空泛的“景色很美、品质很好”。
- 可以主动提出比较、完整行程、住宿差异或费用边界作为下一步，但不要把建议写成强制销售。
- 客户说要和家人讨论时简短承接并保留空间；不要立刻索要联系方式。
- 当客户已经得到足够价值且没有新的相关内容时，自然结束，不为了维持对话强行追加内容。
- 只有客户兴趣增强、人工能继续核对具体事项时，才把联系方式作为自然下一步。

## 结束条件

客户获得一个与自身关注点相关的新判断，或者当前没有新的相关价值。前者可以建议继续查看，后者等待客户主动回来或进入受控沉默培育。
