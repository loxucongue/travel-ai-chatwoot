# 接待后台交互原型

打开 `reception-workbench.html` 即可使用，无外部依赖。若浏览器限制本地存储，可在项目根目录运行：

```powershell
python -m http.server 9195 --bind 127.0.0.1 --directory docs/product/prototypes
```

然后打开 http://127.0.0.1:9195/reception-workbench.html 。

对应完整设计：`../reception-workbench-design-20260927.md`。

可以操作：

- 四个配置入口和二级页签。
- 两条线路切换、介绍组新增/排序/删除、修改文字及间隔、整套预览。
- 通用和线路话术编辑、启用/停用、新增、素材引用选择。
- 开场文字预览、联系渠道、沉默时间、本浏览器草稿保存。
- 手工推进完整介绍、插入普通问题、集中交给答疑任务、模拟停止/改线/转人工。

原型不连接业务 API，不调用模型，不发送消息。连接设置为字段归属展示；完整介绍编辑展示文字后接素材的基础组合，逐块排序、单组时间覆盖、真实上传/素材替换、搜索/继承专属化、版本恢复等完整行为以设计文档为准，未假装接通。

文本、连接信息和图片均为设计示例。占位素材不代表已批准产品事实。原型队列只演示操作顺序，不能证明真实/演练后台队列已经实现。
