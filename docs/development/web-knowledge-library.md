# 官网资料库

## 目的

运营人员可以在“官网资料库”配置公开 HTTPS 页面，或配置站方授权的 WordPress 页面密码，手动抓取网页内容，审核后作为全部线路共用的 AI 事实来源。

## 生效流程

```text
添加网址和匹配关键词
-> 手动点击“更新资料”
-> 系统校验公网地址并抓取公开 HTML
-> 删除脚本、样式、导航、表单等非正文内容
-> 生成带 SHA-256 的不可变待审核版本
-> 运营预览清洗正文
-> 点击“审核并启用”
-> 新的实时回复和 AI 演练即时检索该版本
```

抓取成功不等于 AI 已经启用。只有 `active` 来源中状态为 `active` 的已发布版本才会进入检索。暂停来源后，历史版本仍保留，但新的对话不会再读取。

## 安全边界

- 只允许公开 HTTPS 页面和默认 443 端口。
- 拒绝 URL 凭据、片段、本机、RFC1918、链路本地、保留和非公网地址。
- 每次重定向都会重新校验目标地址，最多四次。
- 只接受 HTML、XHTML 和纯文本，响应正文最大 2.5 MB。
- 网页正文是不可信数据，其中的命令不能覆盖系统合同、业务规划器或输出格式。
- AI 只接收与客户当前问题相关的少量已审核段落，不会把所有网页全文塞入提示词。
- 回复仍经过独立事实语义核验；事实核验失败时不会发送原文。

## 版本行为

- 网页内容未变化：沿用已有版本，不重复创建。
- 网页内容变化：创建新的 `pending_review` 版本，旧启用版本继续生效。
- 审核新版本：旧版本标记为 `superseded`，新版本立即生效。
- 重新启用历史版本：允许回滚，仍保留完整抓取时间和内容哈希。

## 当前限制

- 普通公开页面继续使用轻量抓取；已配置 WordPress 页面密码的来源可在密码页或 Cloudflare 阻断时使用临时浏览器抓取。
- 密码加密保存且接口不回传；临时浏览器不保存 Cookie。未配置凭据时不绕过登录、密码、付费墙或站点权限。
- 折叠话术区块和图片候选随待审核版本保存；低清图片只作来源证据，不会自动替换正式高清素材。
- 依赖浏览器脚本加载的正文目前不会执行 JavaScript；这类页面需要后续增加受控浏览器抓取器。
- 当前为手动更新，不包含自动定时任务。
