下一步应怎样改

  1. 先把讨论目标、正式推荐、已选线路与客户偏好分开；不能为了读取另一条线路的资料或报价，就要求进入推荐流程。偏好提取应由已有语义节点结合原话判定，生成回答时不能把事实疑问或猜测直接写成永久偏好。不要用“不去珠峰”几个字作判断。
  2. 把经验从整组常驻指令收窄为本轮相关的少量已审核案例，保留客户问题、顾问处理思路及当前线路事实依据；用语义检索选择，不堆固定关键词和更多禁止句。
  3. 产品事实、服务承诺与沟通方法分开审批。餐厅协助等未确认服务先不学习；缺少依据时可答已知部分，不必直接整轮转人工。
  4. 用未参与调试的对话复核：能否直接答、是否新增无依据承诺、是否乱记偏好、是否多问、正常报价是否保留。未经这轮验收，不扩大范围或启用生产。

本轮没有启动完整后台审批页面或自动回流工程；也没有给新模型训练权重。保留的候选及失败案例用于下一轮设计，当前不建议仅靠再加几句提示词就上线。
