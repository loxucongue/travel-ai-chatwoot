# China2Go 前两条线路真实 AI 回复验收

## 当前链路

```text
Facebook 测试账号
-> Chatwoot Cloud / Account Webhook
-> Cloudflare Relay
-> 本地 Live Reply Worker
-> 拉取该客户在同一 Inbox 的完整公开历史
-> DeepSeek 判断线路、意图、槽位和内容组
-> 已审核线路规则绑定文字与图片
-> 发送前再次读取标签、人工状态和 can_reply
-> Chatwoot 文本/图片消息
-> Facebook 测试账号
```

只有同时满足以下条件才回复：

- Account `180474`、Facebook Inbox `128859`。
- 会话存在 `ai` 标签，平台本地 AI 状态同步正常。
- 没有人工接管、黑名单、拒绝联系等阻断。
- `can_reply=true`，且最新客户消息仍在自动消息窗口内。
- 最新消息尚未被人工回复，且不是重复 Webhook。

- 9 日参考价人民币 9,980 元/人，单房差 2,600 元。

AI 必须转人工：

- 实时名额、是否确认成团、最终成交内容。
- 长者、儿童、健康证明、入藏资格及医疗建议。
- 氧气浓度、不会高反等医疗效果。
- 无购物、赔偿 5000 等合同承诺。
- 其他月份或资料中没有的线路。

## 会话 #26 测试顺序

从 Facebook 测试账号逐条发送，每次等待回复完成后再发下一条：

1. `想了解明年的林芝桃花行程`
   - 预期：询问 9 日还是加珠峰 11 日，不擅自发图。
2. `我要9日不上珠峰，我们两位，3月底出发，先看完整行程`
   - 预期：回复 9 日线路介绍并发送 9 日行程图。
3. `住宿和房间条件怎么样？有图片吗？`
   - 预期：发送住宿安全说明及酒店参考图，不承诺实际房型。
4. `9日行程一个人价格多少？`
   - 预期：回复页面参考价和费用范围，不转人工。
5. `现在还有余位吗？`
   - 预期：转人工，不编造名额。

测试 11 日线路前可直接明确切换：

1. `改成桃花加珠峰11日，想先看行程`
2. `珠峰那晚住哪里？想看住宿图`

预期分别发送 11 日行程图和绒布旅馆参考图。切换线路会重置该会话的线路进度，但同一图片的跨 AI/SOP 发送记录仍保留。
