## 发布判断

代码能启动和单测通过只代表工程回归。发布建议必须同时说明核心业务、执行安全、回复质量和性能是否通过。旧计划明确的门槛不能在看到失败后悄悄降低。确实缺少批准资料时，先完成其他可开发工作并提供待审材料；不得把未批准文件写为已批准，也不得把转人工冒充已提供附件。

不再把剩余代码开发描述为外部阻塞。真实渠道未发消息这一边界必须如实说明，不能声称已进行真实客户验收。
