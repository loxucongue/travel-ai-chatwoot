# 配置收敛交付记录

目标：只保留当前有效的配置入口，删除旧页面及配置 API，保持原有 UI 风格，说明配置如何进入实际接待。

产品说明：`../product/configuration-workbench-20260927.md`。

## 改动

- 公共接待收敛为四个页签；新增可编辑的通用场景话术。
- 开场只交付配置列表，移除自动附加尾问；支持纯素材和素材结尾。
- 使用局部 PATCH，避免线路页与公共接待互相覆盖。
- 正式沉默开关由后台设置控制，兼容原环境默认值；状态接口同步显示实际值。
- 线路说明接入 Skill；线路列表沉默节点改用 V2 间隔。
- 官网知识按实际发布版本和范围展示，修改范围不会意外发布另一版草稿。
- 系统设置显示真实模型及有效等待参数，删除旧 Adapter 配置和阻断逻辑。
- 删除旧回复、唤醒、SOP 页面、专用编辑器、样式、请求模型及 API；保留实际使用的执行器和记录组件。

## 验证

已完成配置与开场定向 92 项、接口迁移 58 项、交付回归 114 项通过（2 项缺测试素材跳过）；新增纯素材开场及旧 Adapter 不干预当前回复检查通过。

前端测试、TypeScript 和构建通过。Playwright 使用独立数据库及关闭出站的本地服务，验证开场/间隔保存刷新、通用话术增改、沉默间隔保存、运行等待参数保存，并检查桌面与手机布局。未调用真实模型，未向客户发送测试消息。

第一次完整回归：1415 通过、15 失败、52 跳过。失败包括已删除接口、旧开场自动尾问、旧 Adapter、旧版本标识等断言；这些测试已按现有合同迁移。发送顺序、重启续发、附件失效和人工接管等执行测试保留。最终全量结果及发布状态在完成后追加。

最终候选全量：1429 通过、2 失败、52 条件跳过、12 警告。仅剩两条旧断言仍要求 V2 沉默节点包含 V1 的固定内容候选；更新为检查实际加载的 Skill 介绍和旧快照不变，相关四个测试模块复验 **101 项全部通过**。没有更改业务代码来绕过这两项，没有重跑第三次全量；上述为实际执行批次记录。当前无未解决失败。跳过项不计为通过。
