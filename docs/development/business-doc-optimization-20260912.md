## 已修复的原因与行为

| 原因 | 修改后行为 |
| --- | --- |
| 普通问候被误认为已完成产品首轮 | 区分选线问候和实际产品内容；先问候再选线也完整发送品牌、桃花、行程、酒店、车辆，最后问一个问题。 |
| 小费被并入团费主题 | 独立小费主题及审核事实；回答每人每天人民币30元，不复述团费，不自行计算整趟总额。 |
| 用药问题套用个人健康模板 | 独立药物主题，直接承接药名；医师/药师负责评估，不捏造客户既往高反经历。 |
| 健康适宜性被交给旅游顾问 | 顾问只确认行程与服务，个人健康交医师，不把供氧当成效果保证。 |
| 纳木错问题仍介绍一串城市 | 独立景点包含主题及简短审核答案，明确未安排纳木错。 |
| 固定天气答案不经过语气生成 | 修改固定审核文本为山口、洋葱式穿搭、保暖中层、防风防水外套等用词。 |
| 只回答人数后重讲产品和留资理由 | 理解节点标记纯资料补充；正文短承接，留资帮助只在最后一句表达。 |
| 代码替换、删除句子产生生硬短语 | 不再将“比較”机械替换为“對照”，不再静默删除设施效果子句；不合格输出由生成节点重写。 |
| 修正调用重复返回被拒绝正文 | 生成类节点把错误和被拒绝正文作为同一请求中的结构化修正资料，最多两次调用，不关闭校验。 |
| 两个进程同时建立相同任务 | 数据库按会话、代次和到期批次竞争处理权；落败进程不创建重复任务。 |
| 并行测试互相推进所有会话 | 测试驱动只入队、推进所属会话；新增会话隔离与过期处理权测试。 |
| 旧评分器误判否定句 | 允许“不代表一定不会高反”等明确否定，不允许肯定保证；新增正反及混合语境测试。 |
| 首轮末尾问题没有登记，沉默阶段重复问人数 | 最后问句携带线路配置中的问题内容组；演练和真实发送共用送达记录，未发送不记为已问。 |
| 指定饭店资料不足仍强配另一饭店图片 | 无证据的核对回复可不带图片；事实重写清除素材、追问及覆盖状态，独立复验后才可发送。 |
| 大团转接说明被要求同时答完整产品问题 | 核验按转人工动作检查承接说明，附带产品结论仍须有证据。 |
| 图片介绍两句话重复同一内容 | 增加句间重复检测，退回正文重写，不以换词视作新价值。 |
