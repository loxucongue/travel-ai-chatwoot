| 用地名走法堆砌，缺少卖点 | 重整桃花秘境、住宿和用车介绍；按真实聊天提炼表达 | 内容审查及实际模型回答 |

| 车辆介绍不具体 | 座椅图、供氧设备图配套说明实际配置 | 内容核对及演练 |
| 问句被后续图片淹没 | 主线结束后单独发送一个追问 | 多轮演练 |
| 人数已知、日期未定仍追问 | 已知字段不再询问；未定日期不再追问，留资不依赖日期必填 | 多轮演练 |
| 酒店图片重复 | 按已送达素材及内容组记录去重 | 本机演练；本次未重复真实客户发送 |
| 沉默只催问、出现“比较” | 从未介绍的景点选择内容；无新价值时不硬发 | 多个沉默节点，不声称本轮走完所有计时周期 |
| 纳木错问题答非所问 | 直接回答是否包含，不再复述整条走法 | 原文问题复测 |
| 随队医生回答不明确 | 直接说明已公布服务安排，不让顾问替代医生判断 | 回答覆盖测试；不等于医疗服务履约审计 |
| 高反回答理工化、套用不存在的经历 | 承接具体线路配置，不虚构既往史，不承诺降低个人风险 | 原文问题复测 |
| 红景天、丹木斯没有针对性回答 | 针对药物咨询，明确交由医师或药师评估，不夹带人数问题 | 原文问题复测 |
| 价格不直接、信息不完整 | 报价列出价格、住宿计价、日期及含不含项目；补齐4至6人适用依据 | 原文与68条历史问题回放 |
| 问小费却重复团费 | 独立小费主题与已审核每人每天30元口径，不擅自倍乘 | 原文问题复测 |
| 需要人工时应有接管提示 | 明确人工请求、达到8人及留资后执行接管状态和任务 | 本机演练通过；普通健康咨询不自动等同转人工 |
| 台湾用语不自然 | 调整生成规范与固定文字，去除机械表达和不合适的天气用词 | 样本审核通过，自然度仍需业务持续盲测 |
| 线路资料只能编辑、不能增删 | 新增、删除及主线关联，删除检查引用，发布保留旧版本 | 后端与页面测试 |
