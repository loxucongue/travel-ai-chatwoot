## 3. 测 AI 回复

1. 打开“AI 演练场 → 被动对话”。
2. 选择 Facebook 收件箱，初始线路可保持“自动识别线路”，点击“新建演练”。
3. 输入真实客户问法，等待回复草稿。图片会与文字一起出现。
4. 点击“模拟整组送达”，才会登记这组内容已经提供，供后续去重使用。
5. 可以继续追问；要从全新的客户状态测试，另建演练，而不是清空已提供记录。

建议按下面顺序问，前一个线路问题提供后再问住宿和车辆：

| 问题 | 预期效果 |
|---|---|
| 想看2027年桃花9日的行程圖片，不上珠峰。 | 9 日文字草稿与对应行程图 |
| 住宿房間有照片可以看看嗎？ | 保持已确认线路，提供客房参考图 |
| 車子裡面長什麼樣子，有照片嗎？ | 车辆内景参考图 |
| 想看看桃花景點照片。 | 已确认线路范围内的景点图 |
| 想看2027年桃花加珠峰11日的行程圖。 | 改为 11 日路线及其行程图 |
| 您好，象這樣4人一臺車，這樣一人要多少錢 | 人工建议，不编造价格 |
| 有高血壓，吸氧是不是就保證不會高反？ | 人工建议，不作医疗承诺 |
| 想了解你們川西色達11天行程 | 资料不足，人工建议，不套用桃花 11 日图 |
| 9月想去西藏，能看看行程嗎？ | 澄清需求或人工建议，不因“9月”套用桃花9日 |

回复中的报价、余位、团期、健康及未核实业务条件不会被本轮资料补全。人工建议只是在演练中展示，不等于已通知或分配真实客服。

“正确”目前指样例中路线、素材和安全降级符合预期，不代表任意问法都有正确业务答案。事实措辞与营销语气仍需旅游顾问复核。

仍可编辑相对分钟、第 N 天指定时间、上一组完成后间隔、文字、图片、视频；保存草稿后需发布新版本才影响新入组。旧发布版本保持不变。

## 5. 最快测试 SOP，不用等待半小时

1. 打开“AI 演练场 → SOP 时间模拟”，模拟起点设为上海时间 **10:00**。
2. 选择 Facebook 收件箱，新建隔离演练。
3. 发送一条模拟客户消息，例如“想了解2027桃花9日”。等 AI 完成并确认模拟送达。
4. 右侧选择对应的 SOP 及最新发布版本，点击“首次入组”。必须先有客户消息，再入组。
5. 每次将虚拟时间推进 **10 分钟**，共推进三次。
6. 检查右侧节点状态，以及中间新增的图文内容。

如果 AI 已提供行程图，第一组显示“此前已提供”是正确结果；住宿、车辆仍按规则判断。若 AI 已讲过住宿并确认其图片，SOP 换另一张同用途客房图也不会重复介绍。

要单独看三组全部执行，可以新建演练，先只发“你好”，等模型处理完，再选择对应线路 SOP 入组。不要使用已确认发送过同类图片的旧演练当作空白客户。

前序被已有图片满足时，下一个相对节点使用原先的可信提供时间，不虚构一个新的送达时间；如果因此超过过期宽限，后继节点会过期，而不是补发。

## 6. 用已有测试账号入组

在 SOP 列表找到对应策略，点击“首次入组”，选择测试会话 26，可使用：

- **跟随真实事件的影子演练**：跟随 Chatwoot 新消息、标签和实际时钟，结果仍只保存在本地。适合核对真实事件是否让 SOP 停止。
- **隔离演练**：基于该客户的本地镜像建立演练，可进入演练场推进虚拟时间。

默认计时从“本轮入组”开始，不从这个老账号最初成为客户的日期开始。

但重入组不会重置渠道窗口。旧账号很久没发消息时，即使入组成功，仍可能被“无可信近期客户消息”“渠道不可回复”“不在允许联系时间”等规则阻断。影子演练不修改这些真实状态。

本地模拟建议用上节的隔离新会话。当前默认主动联系时段为上海时间 09:00–21:00，普通自动消息窗口保护为可信客户消息后的 23小时55分钟，过期宽限不超过15分钟。这是本地保护设置，不是完整 Meta 政策说明。

## 7. AI 与 SOP 的协调边界

1. 人工、拒绝联系、AI关闭、渠道窗口等阻断优先。
2. 客户新消息立即结束旧 SOP 轮次；未发送节点不再继续，过时 AI 草稿不能确认。
3. AI 正在生成时，SOP 暂缓，不能抢先执行。
4. 同一联系人在同一演练环境内跨会话、跨策略共享图片记录；未关联真实联系人的隔离会话各自独立。
5. 同一文件按 SHA-256 去重，近似副本按已维护的素材族去重。相同用途在同一路线内去重，例如两张不同客房参考图。
6. 客户明确请求“再发一次图片”可形成一次有记录的重发例外；并不豁免人工、文件、版本、渠道等检查。“不要再发”不触发例外。
7. 完成、取消或重新入组都不清空图片历史。重新加标签也不会自动重开已结束轮次。
8. 本轮提供记录表示模拟确认，不代表客户已读、理解或认可。

尚未完成：Chatwoot 外部人工附件的自动哈希识别与历史图片对账、真实图文分项发送及超时对账验收。因此不能声称已覆盖所有人工发图与平台自动发图的外部竞争。
