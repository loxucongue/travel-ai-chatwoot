## 590的具体问题

1. 客户问青铁入藏。AI知道林芝进、拉萨出，却直接扩展成票务、车次和顾问另排进藏。AI(2).docx第10段已给口径：桃花产品林芝进、拉萨出，建议出藏时选青藏铁路。应先直接说明这件事；客户坚持铁路进藏才处理特殊衔接。
2. 客户问集合。AI答出林芝接机，但多讲第一天景点、最后一天送机。AI(2).docx第14–15段给了林芝集合、第一天接机、成都专人交函，并明确要求针对问题回答。集合和交函要分清，不需要每次一起复述全程。
