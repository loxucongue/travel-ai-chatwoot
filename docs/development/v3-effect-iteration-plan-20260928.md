# V3 接待效果迭代目标

基线：[连续效果报告](v3-effect-review-20260928.md)。本轮不重建架构、不增加话术审核调用。

## 目标与完成条件

| 维度 | 本轮完成条件 |
|---|---|
| 台湾语气 | 清除已发现的源话术错字；不连续重复无必要的留资/登记/免责声明尾句；逐条阅读，至少90%的非SOP回答无需重写，其余只需语气小改 |
| 顾虑处理 | 随身氧气查询、两人总价、切换讨论线路、日期未定等基线失败在首次回答中解决；未知项目明确到具体事项，不编住宿设备或留车安排 |
| 留资 | 高意向场景和复测能主动询问一种联系方式；客户未回应继续追问、拒绝、低意向时不反复催；收到ID保存并交接 |
| 沉默 | 真实等候3分钟和5分钟；预约能履行，无相关新信息可不发；未请求重新介绍时不重发；拒绝或交接后不继续营销 |

工程检查只证明执行链正常，不替代这些效果判定。合成客户留资不换算为真实转化率。若关键条件仍未达到，最终必须列明，不以预算或轮数结束为“达标”。

## 优化范围

第一版：短官网事实直接可见；重写通用接待方法的冲突段落；原话选段与总价计算；当前讨论对象与入口选线分开理解；修正线路留资场景和明显错字。

第二版：仅依据第一版真实对话失败调整，不针对某一句做字符串兜底；保留第一版证据，重新跑关联长对话。

后续版：只有关键失败仍存在才继续。最终冻结版本再跑统一验收与必要工程检查。

## 对照方法

八位客户沿用C1—C8的身份、目标、关联提问；两位R1/R2重点复测高意向和住宿沉默。按实际回答分段调整追问，固定基线问题仍保留以便比较。每段主对话至少10条客户消息，含真实的路线名称入口、完整SOP、追问、意向变化。

原始线上配置只读复制到测试数据库。自然沉默场景的测试副本设置[3,5]，逐次间隔；预约3/5分钟另测。全程禁止客户渠道写入。候选版本分别部署到隔离目录运行，完成前不替换生产代码。

每版报告保留原文、交付时间、决策/工具记录、实际模型请求及费用。模型沿用DeepSeek Flash，费用账本跟踪；不重放真实客户消息。
