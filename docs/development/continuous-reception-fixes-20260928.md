## 修复内容

- 首次配置开场与模型续答分开，避免重复问候；已选线不再问选线。
- 比较和查询不作为客户选线；明确选线才绑定。支持线路间的切换直接接待，不创建不必要的人工确认。
- 统一读取普通值和带来源的客户记忆；选线前报过人数，选线后使用对应人数话术。
- 普通插问排队；停止、改线、真人请求及时中断。停止后回来提问只答疑，除非明确要求重新介绍，不自动重启 SOP。
- 选择联系渠道不等于取得联系方式；联系同意与预约时间分开。
- 多类资料分别编排；取消“总素材最多两项”的提示词限制，PDF 不占图片名额。
- 当前明确索取的图片允许重发；按实际素材更新交付记录，已发 PDF 不在留资时自动再发。
- 预约时间进入调度；未来交付的确认不记作已交付，也不提前发图。
- 历史事件不重写为本轮客户事实；去掉进入模型的冗余内部快照。
- 住宿比较工具补充绒布住宿资料；两条线路 Skill 加入机票代订与本线费用的衔接范例。
- 验收脚本把意外 blocked 与 failed 都算失败，不把没有回答算完成。

没有新增话术审核模型。介绍期间的短模型调用只判断排队、停止、改线或人工动作。
