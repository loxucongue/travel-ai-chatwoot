# V2 话术链路简化记录

日期：2026-09-27。范围：移除生成后审核、接入已有线路话术、简化相关编辑界面；没有部署。

## 改动

- V2 删除事实审核、范围审核、任务审核、状态修订、文案修订/裁剪、问句修复和并行审核池，共八个专用模块；删除专用审核验证脚本。
- V2 不再对正文执行繁简转换、地域词替换、问句数量拒绝及生成后字数拒绝。格式解析和素材编号解析仍执行；格式不合法时最多一次结构修复。
- 已配置的开场、资料段落和 SOP 仍由现有交付编排生成发送项目。普通问答正文保持模型原文。
- 清除两套无调用者的开场关键词判断；首次进入只判断过去的客户消息，相同文本不会触发重复开场。
- 线路 Skill 加载当前有效线路包中已启用的 fixed_answers，以及介绍段落、事实引用和素材编号；数据采用副本，避免模型工具结果污染配置。
- 删除线路配置保存时的地域用词拦截；表单以“场景话术”表达原文优先、允许上下文调整的用法。
- 话术编辑器可引用本线路所有内容组的素材，变更话术所属内容组不会悄悄删除其他素材引用。
- 删除接待策略页面中没有编辑功能的“系统保护（只读）”组件和专用查询。
- trace 使用 model_output / delivery_plan，记录 schema_repair_ms 和 direct_model_output，不再伪造审核成功或修订耗时。

仍被 V1 调用的共享验证器保留，删掉其中全部 V2 分支和已无使用者的 V2 字段。V2 不再调用该验证器。

## 测试处理

删除的是已移除审核模块的单元测试、审核改写断言和专用审核样本测试；保留同文件中的资料交付、事件、客户状态、计费和恢复测试。没有把旧测试改成永久跳过。替换后的测试验证原文直出、无审核请求、配置加载和开场入口行为。

同时修正一处既有测试导入：使用本项目已有的 test_v2_service_acceptance 导入方式，避免被环境中的同名 tests 包遮蔽。
