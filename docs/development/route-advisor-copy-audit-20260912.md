## 人类归因边界

按互斥规则计数：私密或缺失公开标志 → 删除消息 → 客户 incoming → 系统/其他类型 → 本项目已登记 AI/SOP 或显式机器人/自动化 → User 且属于 agents 清单 → external_echo → 归因未知出站。

1. 项目 `outbound_messages` 通过 Chatwoot 消息 ID 关联，`source_type=ai/sop` 排除；不能只依赖本地 `inferred_human`。
2. 发送者为 AgentBot/Captain、存在 `automation_rule_id` 或返回的 `campaign_id` 时排除。API 没有返回的隐藏元数据不能视为已检查。

4. `external_echo=true` 表示从原生渠道回传，不代表可验证顾问身份。以下样例全部属于这个低一级来源类别，保留原话但不进入“确认人工”语料。
5. 本地 Chatwoot 源码 `Message#human_response?` 也接受 external_echo，但这属于产品统计定义，不是法证级真人归因；生产 Cloud 版本未据此推定一致。
