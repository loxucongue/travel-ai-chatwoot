## 验收口径

- 正向回复必须有实际答案，不能把通用核对提示、空正文或仅模型调用成功算成通过。
- 19个完整演练场景包含两条线路、住宿、供氧、家人讨论、拒绝与恢复、优惠、公司、微信、健康、大团、复合问答、路况、接送、未选线路问价、入藏证与机票，以及灾害状况加微信联系。
- 原来要求解析器自动删句/替换的测试迁移为原始正文保留；额外验证核验拒绝后仅一次重写，持续拒绝则不发送问题正文。原始反例未删除。实际模型反例首轮有3项漏检，记录保留，不用模拟测试替代模型质量证据。
- 易错场景独立重复；68条历史输入与旧断言不变，37条真实输入及14条线路绑定对照另存模型结果。
- 历史旧断言要求自动回复，但新规则要求创建核对任务的情况单列。不得据此把所有转人工改判通过。
- 本轮不验证真实客户渠道端到端发送，不扩大真实账号接待范围。

## 不能编造的资料

| 待核对内容 | 处理边界 |
| --- | --- |
| 实时道路、灾害、口岸与景点开放 | 静态官网或旧聊天不能代表当前状态；创建具体核对任务 |
| 指定日期是否成团、余位 | 已公布出发日不等于该日已成团 |
| 利源、波密希臻等具体酒店及17座车年份 | 通用希尔顿或9座车资料不能代答另一酒店、车型 |
| 九月团期、单女拼房、报名截止日 | 当前桃花线路发布区间和通用住宿资料不支持直接确认 |
| 具体早鸟减价及个别报价 | 客户或历史顾问说过的金额不自动成为当前生效报价 |

上述缺口应补充经过业务确认、可追溯版本的资料后复测；本次不以编造事实提高自动回复率。
