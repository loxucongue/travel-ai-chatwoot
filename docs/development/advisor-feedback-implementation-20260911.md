- 老会话不重复欢迎与品牌介绍；已介绍饭店后不再自动发送同主题 accommodation_summary。
- 日期未定不重复追问；直接问题优先，医疗及日期等问题不附加无关视觉主线。
- 实时和沉默回复增加独立的回答相关性检查；核验失败只允许有限重写，仍失败则不发送，不再删除争议句后直接放行。
- 图片说明不再替换正文；超长回复交回生成节点，不截去客户问题的答案。
- 修复发送资料被误删为重复留资、总览图名称漏识别、素材可选提示与强制发送规则冲突。
- 演练失败追踪保留具体错误码、核验原因和请求摘要；验收脚本把失败的沉默节点计入失败。
