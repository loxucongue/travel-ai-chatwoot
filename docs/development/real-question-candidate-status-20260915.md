## 发布结论

尚未达标，不部署。本轮没有修改真实发送开关、AI 标签门禁或白名单，没有向 Chatwoot 提交客户消息。

## 已修改

- 客户理解增加讨论对象、子问题和原文承接证据；历史引用须对应同一公开消息的 ID 与原文。
- 官网候选知识在理解后按问题选择；联系方式不再因“微信”而匹配微信支付。
- “暂时不用”等暂停信号要求当前客户原文证据。真实回复分支取消后续 SOP；演练一致性仍待验收。
- 核验失败最多进行一次内容重写，仍失败改为专项核对转人工，不发送被拒绝正文。
- 未选线路的具体问题不再被固定选线路开场直接覆盖。住宿、天气等优先获取对应主题事实，仍禁止未选线路图片。
- 运行详情增加问题、讨论对象与知识选择记录。
- 官网便携供氧资料补入候选文件，保留超过 5000 米等适用条件，尚未发布入库。

## 上线前缺口

1. 未绑定线路时不得只给一条线路安排却让客户选择两条；减少无关行程和衣物介绍。
2. 缺少优惠等资料不能推断“没有优惠”；核对任务必须保留原问题、缺失项与失败原因。
3. 演练目前转人工是控制状态与时间线事件；尚未完成独立可核查的模拟核对任务，不应宣称任务闭环已通过。
4. 演练暂停主动触达、客户主动恢复、家人讨论低频触达需完整多节点验收。
5. 人工历史线路证据恢复、多段回答及统一发送执行的完整验收仍未完成。
6. 最终版本重新运行 51 组、重点三次重复、至少 12 个演练场景、全量回归、历史回放和浏览器验收。
7. 全部达到验收标准后再备份、受控发布；真实发送继续关闭，不能自动扩大知识或账号范围。
