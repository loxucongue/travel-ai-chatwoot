2026-11-08 · 核心发布范围验收记录，实际发布另见 deployment.json。

共性根因

旧季节模板、历史价格、新多人优惠和完整报价习惯同时进入上下文，事实权威与回答范围不一致。另有执行层缺陷：quote_options与text并存时正文被舍弃，模型写出的日期、交通说明未发送。

调整后的数据流

本轮客户原话与历史分开 → 模型理解人数、日期、团型、话题 → 按配置确定性核价 → 已核准最终价、未知成本、日期边界与短答交给模型 → 模型选引用或组织正文 → 执行回复与内部通知。

没有新增客户关键词正则，没有生成后删句或改写回复。正文优先保留；未写正文时才展开所选报价引用。结构、引用定位和发送权限仍保留。协议缺失最多额外重试两次，受原60秒期限和总轮数限制；主备选择仍由原传输层负责。

按用户确认，10,480基价的6人方案最终10,080，不再减早鸟600；其他未核准早鸟为待确认，不把未计入误说成没有优惠。

回复范围与交接

区分首次报价、改人数追问、单项答疑与留资确认。同价合并；单项短答以answer_scope配置标记，由模型理解话题后选资料。留资仍通知内部顾问，对客统称专业顾问，不从微信账号推断顾问姓名。原负责人、通知名单、人工接管权限不变。
